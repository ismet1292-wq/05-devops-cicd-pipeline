## Overview

This project demonstrates a complete CI/CD pipeline built with **GitHub Actions**, **Docker**, **Node.js**, and **Ansible**.

Every push to the repository automatically:

- ✅ Tests the Node.js application
- ✅ Validates the Ansible playbook
- ✅ Builds a Docker image
